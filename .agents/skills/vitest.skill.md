# Skill: Vitest

Las pruebas viven en `test/` reflejando la ruta de `src/` y terminan en `.spec.ts`. Para casos de uso, instancia la clase con puertos falsos tipados y comprueba valor y colaboración relevante. Para HTTP usa `createServer().inject()`; para infraestructura simula el borde externo, incluyendo Prisma o `pg`. Ejecuta `npm run test:run`; agrega cobertura y mutación en reglas sensibles.
