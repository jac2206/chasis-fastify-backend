# Skill: Zod + OpenAPI

Registra cada endpoint en un plugin Fastify con schemas Zod para body, params, query y respuestas. `@fastify/swagger` genera OpenAPI desde esos schemas y `@fastify/swagger-ui` sirve la interfaz en `/docs`. Incluye seguridad JWT y los errores relevantes en el schema de cada ruta. Verifica `/docs` tras cambios de contrato.
